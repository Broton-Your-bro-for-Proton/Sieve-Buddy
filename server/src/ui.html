Please first check on the official Proton login that the account is reachable as usual. Only then lift the pause.

To connect the service to Proton, without it signing in with a password itself:

  1. In Thunderbird, open Sieve Buddy and sign in there (if you have not yet).
  2. In the top right corner, click “Hand over to service” to start the hand-over.
  3. Enter the address and the API token.

Password login directly in the service is disabled because Proton may block new sign-ins from unknown programs (ALLOW_PASSWORD_LOGIN=true turns it back on).

The password is used only for signing in (SRP) and is not stored.
