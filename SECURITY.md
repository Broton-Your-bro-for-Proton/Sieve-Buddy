# Security Policy

## Supported versions

Security fixes go into the latest released version. Older versions do not get separate fixes.

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please report vulnerabilities privately under **Security → Report a vulnerability** in this repository.

Do not post any of the following in a public issue:

- working exploits
- credentials, passwords or tokens
- mail content or other personal data

## Helpful details

- affected version of the add-on and of Thunderbird
- operating system
- affected file or feature
- steps to reproduce with harmless test data
- possible impact

## Handling

A report is first checked for reproducibility and impact. A confirmed vulnerability gets a fix, a regression test, a release note and, where it fits, a GitHub security advisory. Details are published once a fix is available.

Regular bugs and usage questions belong in the public issue tracker.
